## Overview

SOLÉRA is a fictional luxury hotel and travel brand. This project presents a complete, elegant landing experience, showcasing destinations, accommodations, offers and guest reviews. It is built entirely with front-end technologies and focuses on clean structure, modern layout techniques and refined visual design.


## Features

| Section | Description |
|---|---|
| **Navigation** | Premium, easy-to-use navigation bar |
| **Hero** | Full-width hero section with strong visual impact |
| **Booking Interface** | Visual search and booking panel |
| **Destinations** | Curated travel destination cards |
| **Accommodations** | Luxury accommodation listings |
| **Special Offers** | Highlighted promotions and packages |
| **Gallery** | Image gallery showcasing properties and locations |
| **Testimonials** | Guest reviews and feedback |
| **About** | Brand story and values |
| **Contact** | Contact form interface |
| **Responsiveness** | Optimized layouts for desktop, tablet and mobile |
| **Interactions** | CSS hover effects and smooth animations |

## Technologies

- **HTML5**: semantic page structure
- **CSS3**: styling and visual design
- **CSS Grid & Flexbox**: flexible, modern layouts
- **CSS Variables**: consistent colours, spacing and typography
- **Media Queries**: responsive behaviour across screen sizes
- **CSS Animations**: transitions and hover effects

## Getting Started

No installation or build tools are required.

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<repository-name>.git

# 2. Open the project folder
cd <repository-name>

# 3. Open index.html in your browser
```

You can also run it with a local server such as the VS Code **Live Server** extension.
